# 🛒 Annette's Mart - Complete Retail Management System

A full-featured, single-file retail management system with POS, inventory, customer credit tracking, expense management, analytics, and multi-user role-based access control.

## ✨ Features at a Glance

| Feature | Description |
|---------|-------------|
| 📊 **Dashboard** | Real-time sales, low stock alerts, weekly trends, expense tracking |
| 📦 **Inventory** | Product management with categories, stock control, buy/sell prices |
| 🧾 **Point of Sale** | Fast checkout, customer selection, discount, tax, multiple payment methods |
| 👥 **Customers** | Credit limit tracking, purchase history, debt management |
| 🏭 **Suppliers** | Supplier management, purchase orders, total supplied tracking |
| 🛒 **Purchases** | Record stock intake, auto-update inventory, cost tracking |
| 💸 **Expenses** | Operational expense tracking by category |
| 📈 **Analytics** | Revenue, profit margins, top products, payment method breakdown |
| 📋 **Reports** | Sales summary, inventory valuation, Profit & Loss statements |
| 🔐 **User Roles** | Admin, Manager, Cashier, Stock Keeper, Accountant |
| 📤 **Import/Export** | CSV/JSON import/export, full backup & restore |
| 🎨 **Branding** | Customizable colors, store info, receipt footer |
| 🗄️ **Multi-Database** | SQLite (default), MySQL, PostgreSQL support |

## 🚀 Quick Start (Local)

### Prerequisites
- Python 3.8 or higher
- pip package manager

### Installation (3 minutes)

```bash
# 1. Clone the repository
git clone https://github.com/incredibledevelops/annettes-mart.git
cd annettes-mart

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the application
python app.py
